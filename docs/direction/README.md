# Direction notes

Film-direction rules for the crew live in [corpus/](corpus/README.md): the ad laws, look recipes, plate-prompt grammar, motion timings,
the critic rubric and lessons from reference product films. What the crew's prompts actually use is in `DIRECTION` and
`BUILDER_DIRECTION` in `server/crew/prompts.ts`, written for our tools: four eases (`linear`, `easeIn`, `easeOut`, `easeInOut`), layers
and keyframes, a 5 % safe area.
