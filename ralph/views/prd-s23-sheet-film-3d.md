Every new product film is made as one 3D film: Muse's board (with lock lines and the asked length), then product, element and set sheets rendered by our own engine and checked in one Muse look, then the film built from JSON, checked by code rules, shown as a film sheet and looked at once, then committed. The 2D crew no longer runs for a new film (FILM_PATH=crew keeps it until a later PRD deletes it). Leaves out: deleting the 2D crew code, an approval gate, chat edits of a 3D film.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner runs `npm run live -- s23-sheet-film --yes` on the test server (PORT 8797, DATA_DIR data-s-review, web on 5199) with the yoghurt photo; it prints the time of every stage and the cost, and writes the four sheets and the film to debug/sheet-film/<stamp>/. Expect about 2-4 minutes and $0.06-0.10.
- MG-2: owner makes one film in the app (FILM_PATH unset): the Plan panel shows the sheets, the film is 3D, the end card names the product, and no 'Out of time' note appears.
