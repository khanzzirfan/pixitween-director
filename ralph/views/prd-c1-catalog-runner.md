Runs the S19 catalogue path from the studio: import a CSV (or the demo feed), build one verified 9:16 retail clip per product in the background, show a live wall with a status and check chip per row and one player, and edit a price with a $0 rebuild. Leaves out showrunner planning, a Spark price read, Publish/MP4, the product page and variant line films.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner runs the studio with real keys (`npm run dev`), opens the Catalog tab, clicks 'Use demo feed (6 products)' and watches 6 rows reach ready/fixed/flagged. First run spends about $0.02 (SAM cut-outs for 2 photos, plates only for looks missing from look-plates.json); a second run must show $0.00.
- MG-2: owner edits one price on the wall (24.00 -> 19.00) three times, stopwatches Enter to new price on screen, and records the median next to the server `ms` the tile shows.
- MG-3: owner plays 3 clips from the wall in Chrome and scores how they look (1-5).
