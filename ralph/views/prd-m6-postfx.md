### US-002: buildPostFxChain: composer, passes, tone mapping swap, draw, dispose

As an engine developer, I want a chain that renders a scene through effects on the shared renderer and leaves the renderer as it found it so that layers without post-processing are not affected.

**Steps**

1. Read engine/docs/05-filters-postfx.md '3D post-processing chain' (composer options, RenderPass clearing to transparent, one EffectPass with ToneMappingEffect last, NoToneMapping during draw then restore, setSize once, render(0)).
2. Create engine/src/three/postfx/chain.ts exporting PostFxChain and buildPostFxChain(renderer, scene, camera, specs, size) returning null when no spec is enabled.
3. resolveTarget(id, prop) returns a TargetRef on a proxy that calls the def's set ('deg' kind for hue).
4. Create engine/src/three/postfx/chain.test.ts with vi.mock('postprocessing') recording constructor calls and passes, and a fake renderer object with a toneMapping field.

**Acceptance criteria**

- [ ] With specs [bloom, vignette (enabled false)] the chain makes one EffectPass whose effects are [BloomEffect, ToneMappingEffect] in that order
- [ ] During draw the fake renderer's toneMapping is NoToneMapping and after draw it is back to ACESFilmicToneMapping, also when composer.render throws
- [ ] buildPostFxChain with only disabled specs returns null
- [ ] dispose() calls composer.dispose() once
- [ ] `npm run typecheck` passes
