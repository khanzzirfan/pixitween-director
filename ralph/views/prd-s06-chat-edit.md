Adds the edit loop that lets a user keep directing a film in plain words: four thin edit tools, runEditWithCtx (bounded, no extra DONE turn), a per-film lock, cost accounting, an optional post-edit rules hook, chat/undo/redo routes, six scripted edits as tests, the Chat panel with the backend badge, canvas picking as the primary selector (through the engine's own `container-<layer id>` labels, no engine change) and a keyboard-accessible layer list as the fallback. Offline only: the model is faked in every test; the live gate (s06-chat) is run by the owner. Leaves out: backend selection (S9), new art (S4), visual review (S5b).
