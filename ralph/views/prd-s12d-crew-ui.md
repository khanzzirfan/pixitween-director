The studio view of a crew film: a pure reducer from events to crew state, the crew board with one lane per agent, director's notes with ask buttons, editable live storyboard cards, the takes picker, the budget meter, push-to-talk to the showrunner, the browser capture bridge for the critic and the crew layout in App. Built against recorded event fixtures so it does not wait for S12b. It also adds the crew map (a live topology of the agents driven only by real crew events), a chat-thread intake that replaces the form for crew films, and an optional phone frame around the thread (cut line).

1. Read web/src/crew/ChatThread.tsx, web/src/crew/CrewStudio.tsx and the theme tokens in web/src/styles.css.
2. Create web/src/crew/PhoneFrame.tsx: a CSS-only device outline (rounded body, notch, status bar showing only the time) wrapping its children, max width 390 px, using the theme tokens in light and dark. No app name, logo, brand colour or read-receipt ticks.
3. Wrap ChatThread in PhoneFrame in CrewStudio and ChatIntake when the 'Phone view' toggle is on (default on at widths of 1024 px and up; remembered in localStorage inside try/catch). Below 640 px the frame is never drawn, because the device is already a phone.
4. When film.status becomes 'ready', add one showrunner bubble 'Your film is ready' with a poster image (the Player's first frame from the existing capture helper, or the product photo if capture fails) and a 'Play' button that scrolls to the Player and plays from 0. For a 9:16 film, the bubble's poster keeps the 9:16 ratio.
5. Create web/src/crew/PhoneFrame.test.tsx.
