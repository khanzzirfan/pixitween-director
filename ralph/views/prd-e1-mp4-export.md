- Stories: 5

Adds a deterministic MP4 export for built films, including the 3D hero films. Headless Chromium seeks the film to every frame time and saves a PNG, then ffmpeg encodes the frames to H.264 (yuv420p, faststart). Runs from a script for one film or a whole catalog. Leaves out audio, a server route, a button in the UI and the browser-side WebCodecs export.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner runs `npm run dev`, then `npm run export:mp4 -- <catalogId> <productId>` for one hero film and plays the file in QuickTime and in Chrome. It must show the same camera moves as the Catalog wall player.
- MG-2: owner runs the export for a whole catalog and records seconds per film and file size. Expect about 1-2 minutes per 8 s film and a few MB (not yet measured).
- MG-3: owner compares three frames (1 s, 4 s, 7 s) of the MP4 against the wall player; flat cut-out products must show the same turn.
