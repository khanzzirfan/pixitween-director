- Stories: 7

Adds a frame-exact MP4 export for any film, including the 3D hero films. The viewer's own browser seeks the film to every frame time and draws it with its GPU. Where WebCodecs H.264 is available, Mediabunny encodes the frames in the page (with the composition's audio). Where it is not, the page uploads JPEG frames to the server, which encodes them with ffmpeg (silent). The server also checks every finished MP4 with ffprobe for length, size, frame count and frozen frames. Judges install nothing: they open the deployed Fly app in Chrome and press Export. No Playwright, no headless Chromium, no CLI.

## Manual gates (owner; Ralph never runs these)

- MG-1 (Chrome, local): open a 3D hero film at http://localhost:5173/?replay=1, choose MP4 and export. Play it in QuickTime and Chrome: same camera moves as the player, audio in sync by eye, no frozen stretch. Note the time taken and file size.
- MG-2 (server path): in Chrome devtools run `delete window.VideoEncoder` (or use Firefox), reload, export MP4 again. The panel must say it is using the server; the file must play and be silent. Note the upload time and size.
- MG-3 (Fly, after the owner deploys): open the deployed app in a browser with no local ffmpeg, export one film by each path, and confirm GET /api/health reports ffmpeg true. Timings in the doc are filled in from MG-1 to MG-3; until then they are estimates.
- MG-4: compare frames at 1 s, 4 s and 7 s of the MP4 against the player paused at those times; flat cut-out products must show the same turn.

### US-002: Check a finished MP4 against the film it came from

2. Create server/media/export-check.ts exporting the type ExportExpect = { durationSec: number; fps: number; width: number; height: number }.
3. Export compareProbe(probe: { durationSec; width; height; frames }, expect: ExportExpect, tol = 0.15): string[] (pure): 'duration A s, expected B s' (two decimals) when they differ by more than tol; 'size WxH, expected WxH' when width or height differ by more than 1 (the encoder rounds odd sizes down); 'frames N, expected M' when the count differs by more than 2 from round(durationSec * fps).
