# App A2: AEP → MotionDoc converter for 2D films (keyframes, transform, shape, text, image, precomp, audio)

- Owns: `web/src/motion/aep/*`, `web/aep-motion.html`, `web/src/dev/aep-motion.tsx`

A pure converter in web/src/motion/aep/ that turns a director AepCompositionJson into a MotionDoc for the Motion engine: frame keyframes become seconds tweens with cubic eases, transforms map with pixel pivots, shape/text/image/precomp layers convert, audio becomes cues. 3D layers become warnings here (A3 converts them). Tested on every stored film.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner opens http://localhost:5173/aep-motion.html?film=<id> for two stored films and compares them with the studio player.

### US-001: Keyframe helpers: frames to seconds, keyframes to tweens, bezier pair to cubic ease

As a developer working on the converter, I want one tested function that turns an AEP property into a start value and tweens so that every layer kind animates the same way.

**Steps**

1. Read engine/docs/10-aep-adapter.md sections 'Time' and 'Keyframes → tweens', shared/aep/transform.ts (keyframe shape: t, v, easeOut, easeIn) and engine/src/schema/parts.ts (Tween).
2. Create web/src/motion/aep/keyframes.ts exporting isKeyframed(value), easeFor(k0, k1): string ('none' or 'cubic(x1,y1,x2,y2)' with numbers rounded to 4 decimals), and propertyTweens(value, { fps, inPoint, props }) returning { initial, tweens } where props names the MotionDoc keys per component (e.g. ['x','y'] for position, ['alpha'] for opacity).
3. A vector keyframe splits into one tween per component in the same fromTo; at is clamped to ≥ 0; a zero-length pair is skipped.
4. Create web/src/motion/aep/keyframes.test.ts.

**Acceptance criteria**
