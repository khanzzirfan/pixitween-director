The 3D product stops guessing its sides. The image model draws one turnaround sheet from the photo (front, three-quarter, side, back), code cuts the views apart and checks that they agree, Muse checks them against the photo with one redraw at most, and three.js wears them: a 360 degree label strip for round products, a back texture for boxes, pouches and outlines. Any failure falls back to today's single-photo body. Leaves out: an image-to-3D mesh service, characters, an approval gate.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner runs `npm run live -- s24-turnaround --yes` (test server, PORT 8797) with a perfume photo and a can photo; open debug/turnaround/<stamp>/compare.jpg and judge whether the drawn body is better than the single-photo body at 90, 180 and 270 degrees. Expect +30-55 s and about $0.045 per product.
- MG-2: owner makes one perfume film in the app: the Plan panel shows the drawn turnaround first in the sheet strip, and the spin shows the drawn back. Set TURNAROUND=0 to compare with the old body.

### US-006: Wrap the views into a 360 degree label strip

As a three.js body for round products, I want a label strip stitched from the front, three-quarter, side and back views so that the bottle shows its true back when it turns.

**Steps**

1. Read server/product3d/unwrap.ts (findBodyBand, unwrapCylinder, LABEL_WIDTH, LABEL_HEIGHT, how the strip's columns map to angle and where angle 0 sits), server/product3d/unwrap.test.ts and server/product3d/pixels.ts.
2. Create server/product3d/wrap360.ts exporting wrapStrip(views: TurnaroundViews, side: Rgb): Promise<{ strip: Buffer; band: BodyBand } | undefined>.
3. For each view find the body band (findBodyBand); undefined when the front view has none. Sample each view's band across its width into angles using x = cx + r * sin(theta), theta from -90 to +90 degrees, so a view covers 180 degrees of the cylinder.

6. Create server/product3d/wrap360.test.ts: four flat-coloured cylinders (different colour per view) give a strip whose column at angle 0 is the front colour and at angle 180 the back colour; a front view with no straight body returns undefined.
