**Acceptance criteria**

- [ ] `isPublicAddress` returns false for `0.0.0.1`, `10.1.2.3`, `100.64.0.1`, `127.0.0.1`, `169.254.169.254`, `172.16.0.1`, `172.31.255.255`, `192.168.1.1`, `192.0.0.8`, `198.18.0.1`, `224.0.0.1`, `255.255.255.255`, `::`, `::1`, `fd12::1`, `fe80::1`, `ff02::1`, `::ffff:127.0.0.1` and `::ffff:a00:1`
