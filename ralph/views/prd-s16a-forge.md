A GPU service (Python on Modal) that turns a masked image into a textured glTF mesh with SAM 3D Objects, rigs humanoid meshes to the Mixamo skeleton with Make-It-Animatable, and turns an acted video into a Mixamo-skeleton clip with Motion2MixamoRig; plus the Director's typed client, a fake forge with fixture GLBs, a clip library importer and a live gate. The crew roles that use it are S16b.

## Manual gates (owner; Ralph never runs these)

- MG-1: owner requests Hugging Face access for SAM 3D Objects and Make-It-Animatable, confirms in services/forge/README.md whether SAM 3D Objects exports a mesh/GLB in our setup (or only a Gaussian splat), and records the answer.
- MG-2: owner deploys the forge to Modal (`modal deploy services/forge/app.py`), sets FORGE_URL and FORGE_TOKEN, and runs `npm run live -- s16-forge` then `--yes` on fixtures/s16a/concept-toy.png and fixtures/s16a/product.png; records seconds and GPU cost per call.
- MG-3: owner downloads ~20 Mixamo clips with an Adobe account (idle, wave, point, present, jump, walk-in, walk-out, clap, shrug, dance) and runs `npx tsx scripts/forge/import-clips.ts <folder>`; the clips stay out of git.

2. Create services/forge/pipelines/sam3d_object.py: run SAM 3D Objects on the image + mask; export a textured mesh as GLB; if only a Gaussian splat is available, convert splat → mesh (density field + marching cubes) and bake vertex colours; decimate to ≤ 20k triangles; centre at origin with the base on y = 0; scale to unit height.
