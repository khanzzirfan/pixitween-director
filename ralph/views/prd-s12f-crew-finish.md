Fixes the five causes found in the MG-2 event log: the showrunner removed the director's sunset scene twice, a queued build for a removed scene failed, slide-in headlines kept failing the safe-area rule, the style bible font was free text, and the finish gate could never pass while critiques waited 90 s for a browser. Adds a deterministic text lane (type and safe area) after every builder job, the film outline in builder prompts, protected user scenes, a fix cap, a finish gate that accepts capped findings, a done nudge with auto-finish, and honest metrics.
