### US-001: assemble(): nodes, filters, presets and tweens on one clock

As an engine developer, I want the whole build pipeline in one testable function without WebGL so that wiring bugs are caught by unit tests.

**Steps**

1. Read engine/docs/06-runtime-player.md section 'MotionRuntime' (the load steps 2 to 9 and the assemble split).
2. Create engine/src/runtime/assemble.ts exporting assemble(doc, { app, textures, factories }) that builds nodes with createNode (walking group children too), builds each node's filters with buildFilters and sets display.filters, runs validateTargets, creates a MotionClock, expands presets with each node's size(), compiles presets and tweens with a resolve that sends 'filter:<id>' to the node's filter set and everything else to node.resolveTarget, applies stage filters to the root, primes the timeline, and returns { root, nodes (flat list), clock, renderAt, warnings, destroy }.
3. Asset load errors are passed in by the caller as layer errors; compile and validation errors become warnings with paths.
4. Create engine/src/runtime/assemble.test.ts using a shapes-only doc (no text, no image, no three) and a doc with a three layer served by a fake factory.

**Acceptance criteria**

- [ ] assemble on a doc with two shapes and one group (with one child shape) returns 4 nodes and root has 3 children in layer order
- [ ] A shape with enter fadeIn has alpha 0 at t = start and its base alpha after the preset's duration (via clock.seek)
- [ ] A tween on filter:g (glow outerStrength 2 -> 0 over [0, 2], ease none) gives outerStrength 1 at clock.seek(1)
- [ ] A tween with an unknown property becomes one warning whose text contains the layer id; assembly still succeeds
- [ ] destroy() destroys every node and the clock (spied)
- [ ] `npm run typecheck` passes
- [ ] `npm test` passes (offline, no network)
- [ ] `npm run lint` passes
